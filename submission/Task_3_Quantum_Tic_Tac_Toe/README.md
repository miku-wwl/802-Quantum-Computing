# Task 3 — Quantum Tic-Tac-Toe

## Deliverables

- `Task_3_Quantum_Tic_Tac_Toe.ipynb` — executed local notebook and interactive
  `ipywidgets` game.
- `Task_3_Quantum_Tic_Tac_Toe_Report.docx` — comprehensive report covering
  purpose, functionality, gameplay, circuit generation, all used gates,
  multiple-game analysis, verification, and limitations.
- `task3_game_evidence.json` — machine-readable seeds, move histories, circuit
  metrics, bitstrings, boards, and scores for four games.
- `game_1_rows` through `game_4_open` (`.qasm` and `.png`) — exact measured
  circuits and diagrams.
- `task3_four_game_summary.png` — visual comparison of all resolved boards.
- `SOURCE_NOTE.md` — course-starter provenance and adaptation boundary.

## Run locally

From the repository root:

```powershell
uv sync --extra dev
uv run python scripts/generate_task3_evidence.py
uv run python scripts/build_task3_notebook.py
uv run jupyter nbconvert --to notebook --execute --inplace `
  submission/Task_3_Quantum_Tic_Tac_Toe/Task_3_Quantum_Tic_Tac_Toe.ipynb `
  --ExecutePreprocessor.timeout=180
uv run pytest tests/test_tictactoe.py
```

The report is generated by `scripts/build_task3_report.py`. It was rendered to
eight pages with Microsoft Word and visually inspected page by page. Rendered
QA files are intentionally excluded from the submission folder.
